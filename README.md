# kennydev.in

A mecha and JRPG themed personal site. It's plain HTML, CSS and JavaScript, with no build step.

- **Title screen**: an RPG main menu (arrow keys and Enter work), a starfield and a mech standing in a magic circle
- **Chapter I · The Hangar**: build a pixel-art mech from different heads, paint schemes, weapons and backpacks, then transform it into a fighter jet or launch it
- **Chapter II · Quest Board**: hunting quests that open a real-time JRPG battle in a pop-up window. Hit the monster's weakness to knock it down, get "1 MORE" turn, finish with an All-Out Attack, or have the pilot call in the mech you built
- **Chapter III · Load Game**: a JRPG save-file screen with a slot for each favorite series
- **Chapter IV · Toy Chest**: toys you can drag and fling, plus open-chest, shake and float buttons
- **Save point**: a glowing crystal at the bottom of the page. EXP, level, gold and loot are saved in the browser
- **Secret**: the Konami code

All art is original and drawn in code: pixel sprites and the mech are built from text grids and layered parts. Series names appear only as text. This is a fan tribute.

## Run locally

Open `index.html` in a browser.
