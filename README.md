# kennydev.in

An arcade-themed personal site built around video games and toys. It's plain HTML, CSS and JavaScript, with no build step.

- **Title screen**: a synthwave sunset and floating pixel toys that shift as the mouse moves
- **Stage 1 · The Claw**: a playable claw machine (arrow keys move it, space drops it, C inserts a coin)
- **Stage 2 · Cartridge Wall**: click a cartridge to boot it on the retro TV
- **Stage 3 · Toy Box**: toys you can drag and fling, with shake and zero-G buttons
- **Secrets**: the Konami code, plus a hi-score saved in the browser

All pixel art is drawn in code from text grids in `script.js`.

## Run locally

Open `index.html` in a browser.
